Which tool do I need?

Pick the question you arrived with, not the name of a calculator.

“How much do I need to save each month?”

Use the savings goal calculator. Add interest only if the goal is more than 18 months away.

“Where does my pay go?”

Use the budget planner. If essentials exceed 70%, the fix is structural, not a spreadsheet.

“Am I prepared for a bad month?”

Start with the emergency fund calculator. It answers the question before you think about investing.

“I have several goals at once.”

Use the goal comparison tool to see the combined monthly cost.

“Can I afford this holiday?”

Run the holiday budget with a 10–15% buffer, then feed the total into the savings calculator.

“What is actually costing me money?”

Run the subscription audit and the grocery unit price check.

Not sure where to start?
